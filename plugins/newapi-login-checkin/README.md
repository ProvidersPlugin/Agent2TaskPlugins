# New API 登录保活与签到

适用于 **New API / One API** 等使用 `/api/user/login` + `Cookie` + `New-Api-User` 鉴权体系的站点。

## 功能特点

- **可视化参数配置**：站点网址、账号、密码全部在 Agent2API 界面中填写，无需修改脚本代码。
- **密码与会话加密保存**：密码和登录后的 Cookie / 用户 ID 均由 Agent2API 加密存储，支持同一插件创建多个独立账号任务。
- **自动会话维护**：定时运行时优先复用缓存会话并校验有效性，过期后自动重新登录；也支持开启「每次定时都重新登录」。
- **两种运行模式**：
  - **登录保活 + 查额度**：验证登录状态并刷新剩余额度摘要。
  - **登录 + 自动签到**：在保活基础上调用签到接口（若站点未开启签到接口会自动降级为保活并提示）。
- **系统通知策略**：可按需选择「仅失败时通知」「每次执行都通知」或「不通知」。

## 导入方式

1. 下载本目录下的 `script.js`（或直接复制其内容）。
2. 在 Agent2API 左侧进入 **「插件」** → 筛选 **「定时任务插件」** → 点击 **「导入脚本/包」**。
3. 导入后点击卡片上的 **「建任务」**，填入站点网址、账号和密码，点击 **「立即登录验证」** 即可。
